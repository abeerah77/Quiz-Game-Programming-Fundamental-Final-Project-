# 🎮 Quiz Game

A console-based Quiz Game developed in **C++** as part of my **Programming Fundamentals** course. This project was designed to strengthen my understanding of programming fundamentals by creating an interactive quiz application with multiple gameplay features.

---

## 📖 About the Project

The Quiz Game allows players to test their knowledge by answering multiple-choice questions across different categories and difficulty levels. The application provides an engaging console experience with score tracking, lifelines, and a persistent leaderboard.

This project helped me apply core programming concepts while improving my problem-solving and logical thinking skills.

---

## ✨ Features

- 👤 Player profile setup
- 📚 Multiple quiz categories
- 🎯 Difficulty level selection
- 📝 Multiple-choice questions
- 🏆 Leaderboard system
- 💡 Lifelines
  - 50/50
  - Skip Question
  - Replace Question
  - Extra Time
- ➕ Suggest new questions
- 📊 Score calculation and result display
- 💾 File handling for storing game data
